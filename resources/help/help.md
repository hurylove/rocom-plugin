# 远行商人

- `#远行商人` / `远行商人`：查询当前轮次在售货物，生成图片卡片
- 每日四轮 `08-12` `12-16` `16-20` `20-24`，每轮货物不同
- 非营业时间 `00-08` 会提示距下一轮开始的时间

# 开轮订阅提醒

- `config/config.yaml` 配置 `subscribe.keywords` 关键词
- 开轮后自动比对货物，命中即推送提醒并附货物图
- 匹配方式为**模糊包含**，商品名、描述、标签任一命中即可
- 默认 `@全体成员`，无权限时自动降级为普通消息
- 开轮后延迟 `120` 秒抓取，失败每 `30` 秒重试，最多 `5` 次

# 赛季异色图鉴

- `#S1异色` ~ `#S4异色`：查询该赛季有异色的初始精灵，生成总图
- 只收录进化位置为**初始**且有异色的精灵，含编号、名称与属性
- 四个赛季分别为 S1 暗夜拾光、S2 狂欢怪谈、S3 铅字幻梦、S4 月涌狂想

# 孵蛋查询

- `#孵蛋查询 <尺寸m> <重量kg>`：按蛋体尺寸与重量反推可能孵化的精灵
- 例如 `#孵蛋查询 0.56 20.504`，数值请用蛋详情里的原始数字
- 单位必须是米和千克，越界数值会被直接排除
- 返回孵化概率、编号、典型尺寸与重量，按概率从高到低排列

# 系别克制

- `#克制 <系别>`：一张图同时给出**我方进攻**与**我方防守**
- `#克制 火 水`：双系倍率相乘，最高 4×、最低 0.25×
- `#克制表`：完整 18×18 总表，行=攻击方、列=防守方
- 别名：`飞行`翼 `格斗`武 `幽灵`幽 `暗`恶 `钢`机械 `超能`幻 `妖精`萌 `一般`普通

# 精灵图鉴

- `#精灵 <名称>`：精灵详情图——普通/异色双立绘、种族值、体重身高、进化链、完整技能表
- `#精灵搜索 <关键词>`：按名称模糊搜索，列出全部匹配形态及其编号、属性
- `#精灵编号 <编号>`：按图鉴编号定位（如 `#精灵编号 001`）
- `#精灵图鉴`：查看用法说明
- 收录 633 个形态（468 条进化线），异色 197 只；名称支持唯一前缀缩写
- 同名多形态用「名称（形态）」点名，如 `#精灵 雪绒鸟（春天的样子）`；只写 `雪绒鸟` 会列出全部形态供选择
- 首次查询会从 Wiki 抓取详情并缓存（7 天），图片下载后本地保存，之后秒出

# 技能图鉴

- `#技能 <名称>`：技能详情图，含属性、分类、威力、耗能、效果、关联机制、技能石获取条件及全部可学习精灵形态
- `#技能搜索 <关键词>`：按名称、描述或标签匹配，显示总数与前 30 条；复制结果中的 `#技能 名称` 部分查询详情，不含属性信息
- 技能查询和搜索均可省略 `#`；发送空参数指令可查看用法
- 详情优先名称精确匹配，其次唯一模糊名称；存在歧义会列出候选，不会擅自选择
- 自学、血脉、技能石分组展示，同名不同形态分别保留；图片多页逐张发送，失败返回完整分段文字
- 优先读取本地快照或有效缓存；缺失或需更新时访问 Wiki，过期缓存会明确告警，网络不可用且无缓存时提示稍后重试

# 活动总览

- `#活动`：查看进行中与即将开启的活动，生成图片卡片
- 封面已缓存到本地，每天凌晨 `01:00` 自动更新
- `#更新活动`：手动立即刷新活动数据（需主人权限）

# 活动到期提醒

- `#活动提醒开启`：仅为本群开启订阅（主人或本群管理员）
- `#活动提醒关闭`：仅取消本群订阅（主人或本群管理员）
- `#活动提醒状态` / `#活动提醒列表`：查看本群开关、阶段与 @全体设置（群成员可查）
- `#活动提醒@全体开启`：为本群开启 @全体（主人或本群管理员）
- `#活动提醒@全体关闭`：为本群关闭 @全体（主人或本群管理员）
- 以上命令仅群内可用，各群独立且默认不订阅；修改仅主人或本群管理员可用
- 全天每分钟检查，默认结束前 `24h` / `6h` 各一次；无事项静默，默认不 @全体
- 同次事项合并图 + 短文，图失败用完整文字；封面只用已缓存本地图片
- 新订阅或重启只补当前最近到期阶段，已结束不补；成功送达持久化去重，失败可重试
- 仅使用有效本地活动缓存，默认 `48h` 内有效，缺失或过期不提醒；每日 `01:00` 更新
- 可在锅巴「活动到期提醒」设置订阅群、@全体群与提醒阶段；@全体名单不自动订阅
