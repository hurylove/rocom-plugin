# 远行商人

- `#远行商人` / `远行商人`：查询远行商人**当前轮次**在售的货物，生成图片卡片。
- 每日四轮，分别为 `08:00-12:00`、`12:00-16:00`、`16:00-20:00`、`20:00-24:00`，每轮货物不同。
- 非营业时间（`00:00-08:00`）会提示距下一轮开始的时间。

# 开轮订阅提醒

- 在 `config/config.yaml` 中配置 `subscribe.keywords` 关键词，开轮后自动比对货物。
- 命中关键词会向 `subscribe.groups` 中的群推送提醒并附带货物图。
- 匹配方式为**模糊包含**，商品名、描述、标签任一命中即可。
- 默认 `@全体成员`，bot 无权限时自动降级为普通消息。
- 开轮后延迟 `120` 秒抓取，失败每 `30` 秒重试，最多 `5` 次。

# 赛季异色图鉴

- `#S1异色` ~ `#S4异色`：查询该赛季**有异色形态**的初始精灵，生成总图。
- 只收录进化位置为**初始**且有异色的精灵，含编号、名称与属性。
- 四个赛季分别为 S1 暗夜拾光、S2 狂欢怪谈、S3 铅字幻梦、S4 月涌狂想。

# 孵蛋查询

- `#孵蛋查询 <尺寸m> <重量kg>`：按蛋体尺寸与重量反推可能孵化的精灵。
- 例如 `#孵蛋查询 0.56 20.504`，数值请用蛋详情里的原始数字，单位必须是米和千克。
- 返回每只候选精灵的**孵化概率**、编号、典型尺寸与典型重量，按概率从高到低排列。
- 越界的数值会被直接排除，因此没有命中时请确认单位与数值是否填对。

# 活动总览

- `#活动`：查看当前**进行中**与**即将开启**的活动，生成图片卡片。
- 图片封面已缓存到本地，每天凌晨 `01:00` 自动更新一次。
- `#更新活动`：手动立即刷新活动数据（需要主人权限）。

# 使用提示

- 请**在每个轮次开始后**再查询，页面数据按轮次更新，开轮后可能有几分钟延迟。
- 图片包含货物名称、描述、价格、限购数量与商品标签。
