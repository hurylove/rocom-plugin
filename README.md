# rocom-plugin

洛克王国世界的 Yunzai 插件。

## 功能

### 远行商人

`#远行商人` / `远行商人`：查询远行商人**当前轮次**在售货物，生成图片卡片。

每日四轮，每轮货物不同：

| 轮次 | 时间 |
| --- | --- |
| 第一轮 | 08:00 - 12:00 |
| 第二轮 | 12:00 - 16:00 |
| 第三轮 | 16:00 - 20:00 |
| 第四轮 | 20:00 - 24:00 |

### 开轮订阅提醒

在 `config/config.yaml` 配置关键词，每轮开始时自动比对货物，命中则向指定群推送提醒并附图。

```yaml
subscribe:
  enable: true
  groups:
    - 你的群号
  keywords:
    - 国王球
    - 粉尘
```

- 匹配方式为**模糊包含**：商品名、描述、标签任一命中即可
- 默认 @全体成员，bot 无权限时自动降级为普通消息
- 开轮后延迟抓取，失败自动重试（应对数据源更新滞后）

### 赛季异色图鉴

`#S1异色` / `#S2异色` / `#S3异色` / `#S4异色`（大小写皆可）：查询对应赛季所有有异色的初始精灵形态，生成专属网格总图。

### 活动总览

`#活动`：查询洛克王国世界当前进行中与 14 天内即将开启的活动，生成图文卡片。
- 自动提取活动标题、分类、起止时间与核心奖励。
- **本地图片缓存**：每日凌晨 01:00 定时从 Wiki 自动抓取最新活动并预先将封面下载到本地缓存（`data/activity_covers/`），杜绝远程网络延迟与偶发丢图，毫秒级秒出图。
- 主人可使用 `#更新活动` 或 `#刷新活动` 立即手动触发抓取与封面下载。

### 活动到期提醒

各群独立订阅，**默认所有群都不订阅、默认不 @全体**。提醒总开关默认开启，仅对订阅群生效。

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `#活动提醒开启` | 开启本群订阅 | 主人或本群管理员 |
| `#活动提醒关闭` | 取消本群订阅 | 主人或本群管理员 |
| `#活动提醒状态` / `#活动提醒列表` | 查看本群订阅、提醒阶段和 @全体设置 | 本群成员 |
| `#活动提醒@全体开启` | 本群提醒时 @全体 | 主人或本群管理员 |
| `#活动提醒@全体关闭` | 本群提醒时不 @全体 | 主人或本群管理员 |

- 所有管理命令仅群内使用，私聊会提示在群内操作；只改变本群设置。@全体设置不会自动开启订阅，无 @全体权限时使用普通消息。
- **全天每分钟检查**，默认在结束前 **24h / 6h 各提醒一次**；同次到期事项合并为一张图 + 短文，图片失败时使用完整文字，无事项保持静默。
- 新订阅或重启只补当前最近到期的阶段，不追补已错过的全部阶段；已结束的活动不补。成功送达后持久化去重，发送失败可重试。
- 仅使用有效本地 `data/activity_cache.json`，默认缓存 **48 小时**内有效；缺失、失效或过期则不提醒，不使用旧静态数据兜底。活动缓存每日中国时间 **01:00** 更新，主人可用 `#更新活动` 手动更新。
- 提醒期间不联网补封面，仅使用已缓存本地图片；缺图显示占位。提醒图片显示活动名、分类、奖励、截止时间（中国时间）、剩余时长与提醒阶段，不截断本次事项。

### 孵蛋查询

`#孵蛋查询 <尺寸m> <重量kg>`：按蛋体尺寸与重量反推可能孵化的精灵，例如 `#孵蛋查询 0.56 20.504`。
- 返回每只候选精灵的孵化概率、编号、典型尺寸与典型重量，按概率从高到低排列。
- 双系叠加概率由站点计算，越界数值会被直接排除，因此没有命中时请确认单位与数值。
- 精灵图按需缓存到 `data/hatch_images/`。

### 系别克制

`#克制 <系别>`：查询系别克制关系，一张图同时给出**我方进攻**与**我方防守**。
- 可写两个系，如 `#克制 火 水`，双系倍率相乘，最高 4×、最低 0.25×。
- 支持常用别名：`飞行`→翼、`格斗`→武、`幽灵`→幽、`暗`→恶、`钢`→机械、`超能`→幻、`妖精`→萌、`一般`→普通。
- `#克制表`：完整 18×18 克制总表，行=攻击方、列=防守方。
- 系别图标缓存到 `data/type_icons/`。

### 帮助

`#洛克帮助` / `#洛克菜单`：渲染插件帮助图，采用「标题栏 + 分组网格」版式，每格为一条指令及其说明。

### 插件更新

| 指令 | 说明 |
| --- | --- |
| `#洛克更新` | 从 GitHub 拉取最新版本 |
| `#洛克强制更新` | 丢弃本地改动，强制同步到远程最新 |
| `#洛克更新日志` | 查看最近提交记录 |

三者均仅主人可用，底层复用 Yunzai 标准更新器（`plugins/other/update.js`），因此 `git pull`、强制 `reset --hard`、失败提示与自动重启行为与 `#更新` 完全一致。更新后若涉及依赖变动，发送 `#重启` 生效。

## 安装

将本目录放入 Yunzai 的 `plugins/` 下，重启即可。

```bash
cd Yunzai/plugins
git clone <本仓库地址> rocom-plugin
```

无需安装额外依赖：`yaml`、`node-schedule`、`art-template`、`puppeteer` 均由 Yunzai 提供。

## 配置

| 文件 | 说明 |
| --- | --- |
| `config/default_config.yaml` | 默认配置模板，随插件更新 |
| `config/config.yaml` | 用户配置，只写需要覆盖的字段 |

`config.yaml` 已在 `.gitignore` 中忽略——它含有你的群号与订阅关键词，不应提交。

### 活动提醒配置

锅巴面板新增「活动到期提醒」，可设置总开关、订阅群、@全体群、结束前提醒小时与缓存有效期；与商人开轮订阅相互独立。空订阅名单表示没有任何群订阅，@全体名单仅影响已订阅群。

在用户配置中按需增加（不要覆盖原有商人配置或整份 `config/config.yaml`）：

```yaml
activityReminder:
  enable: true
  groups: []          # 群号用字符串，如 ["123456789"]；留空不订阅
  atAllGroups: []     # 默认不 @全体，不能自动订阅群
  hoursBefore: [24, 6]
  cacheMaxAgeHours: 48
```

提醒小时接受 1—168 小时的有限正数，去重并降序排列，无有效值使用 `[24, 6]`；缓存有效小时接受 1—168，非法值使用 `48`。锅巴保存只更新实际提交字段，保留既有商人配置、白黑名单、未提交提醒设置与内部机器人路由记录。

部署或更新时**不得覆盖 `config/config.yaml`**；该文件及 `data/` 是用户配置与缓存/送达记录，应保留。

### 图片清晰度

商人图、帮助图及活动提醒图使用 PNG 无损输出，默认 `renderScale: 200`，即按两倍像素渲染（商人/帮助宽 1440 像素，活动提醒宽 1520 像素）。可在锅巴面板的「渲染缩放」中调整，或在 `config/config.yaml` 中设置 `renderScale`（50–200）。已有用户配置中的值仍会优先保留。

```
├── render/               puppeteer 渲染
├── config/               YAML 配置
└── resources/            模板、字体、帮助文档
```
